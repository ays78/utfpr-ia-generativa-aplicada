## 📖 Sobre o Repositório

Este repositório reúne meus estudos, anotações, exercícios, notebooks e projetos práticos desenvolvidos durante a **Especialização em IA Generativa Aplicada**, da **Universidade Tecnológica Federal do Paraná (UTFPR)**.

O objetivo é documentar minha evolução acadêmica e compartilhar conhecimento sobre Inteligência Artificial, Machine Learning, Deep Learning e IA Generativa.

## 🎯 Objetivos

- Aprimorar conhecimentos em Python aplicado à Inteligência Artificial.
- Estudar algoritmos de Machine Learning e Deep Learning.
- Compreender os fundamentos dos modelos de linguagem (LLMs).
- Explorar aplicações práticas de IA Generativa.
- Integrar Inteligência Artificial à Engenharia e Arquitetura de Software.
- Desenvolver experimentos e projetos práticos.
