# 🐍 Python Exercises | UTFPR

**Fundamentos de Python — Especialização em IA Generativa Aplicada**

Este repositório reúne exercícios práticos, atividades acadêmicas e exemplos de código desenvolvidos durante a **Especialização em Inteligência Artificial Generativa Aplicada da Universidade Tecnológica Federal do Paraná (UTFPR)**.

O objetivo é consolidar os fundamentos da linguagem Python, desenvolver o raciocínio lógico e construir uma base técnica para estudos mais avançados em **Inteligência Artificial, Machine Learning, automação e análise de dados**.

## 🎯 Objetivos

- Desenvolver habilidades de programação em Python.
- Praticar algoritmos e lógica de programação.
- Aplicar estruturas condicionais e de repetição.
- Trabalhar com listas, strings e matrizes.
- Desenvolver soluções para problemas matemáticos.
- Aprimorar boas práticas de desenvolvimento.
- Registrar a evolução do aprendizado ao longo da especialização.

## ▶️ Como executar

### 1. Clonar o repositório

```bash
git clone https://github.com/SEU-USUARIO/python-exercises.git
```

### 2. Acessar o diretório

```bash
cd python-exercises
```

### 3. Executar um exercício

```bash
python caminho/do/exercicio.py
```

Exemplo:

```bash
python 01-fundamentos/exercicio01_media.py
```

Os programas utilizam, em sua maioria, entrada de dados pelo terminal.

## 🧠 Metodologia de aprendizado

Os exercícios seguem um processo de estudo baseado em:

1. Interpretação do problema.
2. Definição da lógica do algoritmo.
3. Implementação em Python.
4. Execução e testes.
5. Correção de erros.
6. Validação dos resultados.
7. Documentação do aprendizado.
