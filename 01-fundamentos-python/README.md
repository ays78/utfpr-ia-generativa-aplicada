## 📚 Sobre a Disciplina

Este repositório reúne materiais de estudo, exercícios práticos, atividades e exemplos desenvolvidos durante a disciplina **Fundamentos de Python**, integrante da **Especialização em Inteligência Artificial Generativa Aplicada**, da Universidade Tecnológica Federal do Paraná (UTFPR).

A disciplina tem como objetivo desenvolver uma base sólida em programação Python, lógica de programação, estruturas de dados e ferramentas utilizadas no desenvolvimento de soluções de Inteligência Artificial.

## 🎯 Objetivos de Aprendizagem

Nivelar e capacitar os estudantes na linguagem de programação Python, incluindo a configuração de ambientes de desenvolvimento utilizados em projetos de Inteligência Artificial.

Ao longo da disciplina, serão desenvolvidas competências em:

- Configuração de ambientes de desenvolvimento Python.
- Utilização de Git e GitHub para versionamento de código.
- Manipulação de variáveis e operadores.
- Desenvolvimento de algoritmos e estruturas de controle.
- Utilização de estruturas de dados fundamentais.
- Criação e reutilização de funções.
- Aplicação dos fundamentos em exercícios práticos.

## 🚀 Executando os Exemplos

**1. Clone o repositório:**

```bash
git clone https://github.com/SEU-USUARIO/fundamentos-de-python.git
```

**2. Acesse o diretório:**

```bash
cd fundamentos-de-python
```

**3. Verifique a instalação do Python:**

```bash
python --version
```

**4. Execute um exemplo disponível:**

```bash
python exercicios/exemplo.py
```

> Substitua `SEU-USUARIO` e `exemplo.py` pelos nomes reais do seu repositório e arquivo.
